Privacy Policy

Last updated: 19 November 2026

Wise Pie Autopost is a private tool used only by the Wise Pie creator to publish Wise Pie's own videos to Wise Pie's own social media accounts (YouTube, TikTok, Instagram, Facebook, Threads).

What it accesses

Only the Wise Pie accounts that the creator connects. It uses each platform's official API to upload videos, set captions and read the account's own basic profile (to check it is posting to the right account).

What it stores

Access tokens for those accounts, stored only on the creator's own computer. No data about other users is collected, sold or shared.

Other users

The tool is not offered to the public and does not collect information about viewers.

Deleting data

Access can be revoked at any time in each platform's app settings; the creator then deletes the stored tokens.
